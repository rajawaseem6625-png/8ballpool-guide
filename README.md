# 8BP Guide

A beginner-friendly, fan-made static website for 8 Ball Pool strategy and skill development.

## Files
- index.html — website structure/content
- style.css — responsive design
- script.js — small interaction layer

## Run locally
Open `index.html` in a browser.

## Deploy
Upload the three files to any static host such as GitHub Pages, Netlify, Vercel, or a web server/Nginx VPS.
